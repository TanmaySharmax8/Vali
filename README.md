# Vali — Personal AI Assistant

> A personal AI assistant for Windows with voice interaction, wake-word detection, local computer control, persistent memory, and an online AI brain.

---

## 🤖 About Vali

**Vali** is a personal AI assistant designed to provide a natural voice-controlled interface for a Windows computer.

The project combines **offline speech recognition**, **local Windows automation**, and an **online AI brain** to create a lightweight hybrid assistant.

The long-term goal is to evolve Vali into a personal assistant that can work across:

- 💻 Windows PC / Laptop
- 📱 Mobile devices
- 🎙️ Voice interaction
- 🧠 AI reasoning
- 🗂️ Personal memory
- ⚙️ Computer automation
- 🌐 Online services

The project is inspired by futuristic personal assistants such as JARVIS and FRIDAY, while being built from scratch as a personal learning and development project.

---

# ✨ Features

### 🎙️ Voice Recognition

Vali can listen to spoken commands using an offline speech-recognition system.

Current technology:

- Vosk
- Python
- SoundDevice
- Offline speech processing
